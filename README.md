# 古法梅花易数排盘工具 | Meihua Yishu

**一个面向传统文化爱好者的轻量级、移动端友好的梅花易数排盘 Web App。**

通过数字、汉字及随机起卦等交互方式，将传统排盘规则转化为可操作、可视化、可保存的数字产品。

**项目状态：** MVP 已开发并部署  
**项目类型：** 个人独立产品 / AI 辅助开发实践  
**技术栈：** HTML · CSS · JavaScript · LocalStorage  
**开发工具：** Codex · WorkBuddy

## 01｜项目背景与需求

### 为什么做这个产品？

梅花易数是中国传统易学文化中的一种起卦方法，涉及八卦、五行、动爻以及本卦、互卦、变卦等概念。

对于希望学习和实践传统排盘方法的用户，手工计算存在一定的记忆和操作成本。

本项目尝试将传统排盘过程工具化，让用户能够通过简单的交互完成起卦、查看结果，并保存记录。

### 核心需求

- **降低操作成本：** 不需要反复手动计算卦象及动爻。
- **支持不同起卦习惯：** 提供数字、汉字和随机起卦方式。
- **提升结果可读性：** 使用结构化页面展示卦象与相关信息。
- **方便日常使用：** 支持手机浏览器访问，无需安装 App。
- **保护使用隐私：** 无需注册账号，历史记录保存在本地。

以上为产品设计阶段的需求判断，尚未经过系统性用户访谈验证。

## 02｜核心功能

### 1. 多方式起卦

支持四种起卦方式：

| 起卦方式 | 功能说明 |
|---|---|
| 两数起卦 | 输入两个数字，根据规则计算卦象 |
| 三数起卦 | 前两个数字确定上下卦，第三个数字确定动爻 |
| 汉字起卦 | 输入两个汉字，转换、核对繁体字及笔画后起卦 |
| 随机起卦 | 随机生成数字并进行排盘 |

### 2. 排盘计算与结果展示

根据选定的起卦方式生成排盘结果，展示：

- 本卦、互卦、变卦
- 上下卦及动爻
- 体卦、用卦及五行关系
- 卦辞、爻辞及相关参考信息
- 起卦输入与计算记录

将计算逻辑和展示界面分离，便于后续独立优化排盘规则与交互体验。

### 3. 历史记录与分享

- 保存排盘历史，便于回顾
- 导出卦象图片
- 分享卦象文字
- 保留起卦时输入的问题及相关结果

### 4. 移动端与隐私体验

- 针对手机浏览器设计交互页面
- 无需登录账号
- 使用浏览器 LocalStorage 保存记录
- 不依赖云端用户数据库

注意：本地记录与浏览器及设备相关，清理浏览器数据可能导致历史记录丢失。

## 03｜产品设计思路

### 用户流程

选择起卦方式 → 输入数字或汉字 → 校验输入 → 生成排盘 → 查看结果 → 保存或分享

### 关键设计决策

**① 提供多种入口，而非单一起卦模式**

允许用户根据自己的使用习惯选择起卦方式。

**② 将复杂结果进行信息分层**

在结果页面中分别展示卦象、体用关系、卦辞、计算记录等信息，减少内容混杂。

**③ 保留计算依据**

展示输入来源与计算记录，使用户不仅能看到结果，也能回顾排盘过程。

**④ 使用本地存储**

在不引入账号系统与云端数据库的情况下，实现基础历史记录功能，降低初期开发和维护复杂度。

### AI 辅助开发流程

项目采用 AI-assisted development（AI 辅助开发）方式推进：

1. **需求定义：** 明确核心功能、操作流程及预期使用体验。
2. **功能拆解：** 将项目划分为排盘逻辑、交互界面、历史记录和结果展示等模块。
3. **开发实现：** 借助 Codex 完成代码生成及功能调整。
4. **迭代完善：** 围绕功能和交互进行修改。
5. **产品部署：** 使用 WorkBuddy 将静态网页发布至可访问的托管环境。
6. **版本归档：** 将最终部署版代码整理并上传 GitHub。

本项目重点实践了从产品需求到技术实现、部署交付的完整流程。
